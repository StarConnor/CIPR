System Performance Testing Tools

Introduction to Stress Testing

Stress testing helps identify system bottlenecks and validate system behavior under heavy load.

stress - CPU and Memory Testing

The stress tool is a simple workload generator:

# Install stress
sudo apt-get install stress

# CPU stress test (4 workers)
stress --cpu 4 --timeout 60s

# Memory stress test
stress --vm 2 --vm-bytes 512M --timeout 60s

# Combined test
stress --cpu 2 --io 1 --vm 1 --vm-bytes 128M --timeout 30s

stress-ng - Advanced Testing

stress-ng provides more comprehensive testing options:

# Install stress-ng
sudo apt-get install stress-ng

# CPU stress
stress-ng --cpu 4 --cpu-method all --timeout 1m

# Comprehensive system stress
stress-ng --cpu 2 --io 2 --vm 1 --vm-bytes 256M --timeout 2m
💡 Tip: Start with short timeout periods and monitor system behavior before running longer tests.

Monitoring During Tests

Use these tools to monitor system resources:

# CPU usage
top
htop

# Memory usage
free -h

# IO stats
iostat

# System load
uptime

Best Practices

  • Test during maintenance windows
  • Start with low load and increase gradually
  • Monitor system temperatures
  • Document baseline performance
  • Have rollback plan ready
