Container and Kubernetes Security

Docker Container Management

List all Docker containers:

docker ps -a
# Shows all containers (running and stopped)

docker inspect container_name
# Shows detailed container information

Kubernetes Secrets

Kubernetes secrets store sensitive data:

kubectl get secrets --all-namespaces
# List all secrets

kubectl get secrets --all-namespaces -o yaml
# Get secrets in YAML format
⚠️ Warning: Secrets contain sensitive information. Handle with extreme care.

Best Practices

  • Use Kubernetes secrets for sensitive data
  • Encrypt secrets at rest
  • Limit secret access
  • Regular secret rotation
