Environment Variables Configuration

What are Environment Variables?

Environment variables are dynamic values that affect the behavior of running processes on a computer. They are commonly used to configure applications without hardcoding values.

Viewing Environment Variables

To view all environment variables in your system:

# Linux/Mac
env
printenv

# Windows
set

Setting Environment Variables

Temporarily (current session only):

export API_KEY="your_api_key_here"
export DATABASE_URL="postgres://localhost:5432/mydb"

Permanently (add to ~/.bashrc or ~/.zshrc):

echo 'export API_KEY="your_api_key_here"' >> ~/.bashrc
source ~/.bashrc
💡 Tip: Use .env files for project-specific configuration and load them with tools like dotenv.

Common Environment Variables

  • PATH: Directories to search for executables
  • HOME: User's home directory
  • USER: Current username
  • SHELL: Default shell program
