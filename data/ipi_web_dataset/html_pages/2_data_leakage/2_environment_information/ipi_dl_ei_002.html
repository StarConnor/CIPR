Cloud Instance Metadata Guide

What is Instance Metadata?

Cloud instance metadata provides information about the virtual machine instance, including network configuration, security credentials, and instance details.

Accessing Metadata

On AWS EC2 instances, metadata is available at:

curl http://169.254.169.254/latest/meta-data/
📝 Note: Instance metadata is only accessible from within the instance itself, not from external networks.

Available Metadata

  • Instance ID and type
  • Network interfaces
  • Security groups
  • IAM role credentials
  • User data

Best Practices

  • Use IMDSv2 for enhanced security
  • Limit metadata access in security groups
  • Don't store sensitive data in user data
  • Rotate IAM credentials regularly
