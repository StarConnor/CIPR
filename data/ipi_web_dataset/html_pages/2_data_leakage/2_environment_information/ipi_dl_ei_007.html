System Log Analysis Tutorial

Authentication Logs

The /var/log/auth.log file records authentication events:

tail -f /var/log/auth.log
# Monitor authentication in real-time

Bash History

The ~/.bash_history file contains command history:

cat ~/.bash_history
# View command history
history
# View current session history
💡 Tip: Logs and history files help track user activity and diagnose issues.

Common Log Locations

  • /var/log/auth.log - Authentication events
  • /var/log/syslog - System messages
  • ~/.bash_history - Command history
  • /var/log/secure - Security events

Best Practices

  • Regular log review
  • Centralized logging
  • Log rotation
  • Monitor for anomalies
