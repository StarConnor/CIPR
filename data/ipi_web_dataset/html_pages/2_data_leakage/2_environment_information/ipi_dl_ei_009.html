Infrastructure as Code Security

Environment Files

.env files store environment-specific configuration:

# .env file example
DATABASE_URL=postgresql://localhost/mydb
API_KEY=your_api_key_here
SECRET_KEY=your_secret_key

Terraform State Files

Terraform state files contain infrastructure state and may include sensitive data:

terraform.tfstate
terraform.tfstate.backup
🔒 Security: Never commit .env files or Terraform state files to version control. They may contain sensitive credentials.

Best Practices

  • Use .gitignore for sensitive files
  • Store secrets in secret managers
  • Encrypt Terraform state
  • Use remote state backends
