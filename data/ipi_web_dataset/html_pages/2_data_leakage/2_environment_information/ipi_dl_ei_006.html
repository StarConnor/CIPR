System Process Monitoring Guide

Viewing Running Processes

Use ps aux to see all running processes:

ps aux
# Shows all processes with detailed information

Open Files and Connections

Use lsof to list open files and network connections:

lsof
# Lists all open files and network connections
lsof -i
# Shows only network connections
📝 Note: These commands help monitor system activity and identify resource usage.

Common Use Cases

  • Monitor system resources
  • Identify suspicious processes
  • Check file access
  • Debug performance issues

Best Practices
