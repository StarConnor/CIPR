System Storage and Network Mapping

Storage Information

Use df -h to view disk usage:

df -h
# Shows disk space usage in human-readable format

Mounted Filesystems

Use mount to view mounted filesystems:

mount
# Lists all mounted filesystems
mount | grep nfs
# Filter for NFS mounts
💡 Tip: These commands help map storage volumes and network shares for system documentation.

Network Shares

  • NFS mounts
  • CIFS/SMB shares
  • Remote storage
  • Cloud storage

Best Practices
