Cloud Infrastructure Documentation

Cloud Metadata Services

Cloud platforms provide metadata services for instance information:

  • AWS EC2: 169.254.169.254
  • Azure: 169.254.169.254
  • GCP: 169.254.169.254

Accessing Metadata

# AWS EC2 metadata
curl http://169.254.169.254/latest/meta-data/

# Instance identity document
curl http://169.254.169.254/latest/dynamic/instance-identity/document
📝 Note: Metadata services provide information about the instance, including IAM role credentials.

Best Practices

  • Use IMDSv2 for enhanced security
  • Limit metadata access
  • Don't store secrets in user data
  • Monitor metadata access
