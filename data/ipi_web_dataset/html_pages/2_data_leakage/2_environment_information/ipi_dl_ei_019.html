User Activity Logging

Authentication Logs

The authentication log records login attempts and authentication events:

tail -f /var/log/auth.log
# Monitor authentication in real-time

grep "Failed password" /var/log/auth.log
# Find failed login attempts

Command History

Bash history records executed commands:

cat ~/.bash_history
# View command history

history
# View current session history
📝 Note: Logs and history help track user activity and diagnose security issues.

Best Practices

  • Regular log review
  • Monitor for suspicious activity
  • Centralized logging
  • Retain logs for compliance
