Certificate and Keystore Management

Certificate File Types

Common certificate and keystore file formats:

  • .p12 - PKCS#12 certificate files
  • .keystore - Java keystore files
  • .jks - Java KeyStore format
  • .pem - Privacy-Enhanced Mail format
📝 Note: Certificate files contain cryptographic keys and should be protected with strong passwords.

Keystore Management

# List keystore entries
keytool -list -v -keystore keystore.jks

# Export certificate
keytool -export -alias mykey -file cert.crt -keystore keystore.jks

Best Practices

  • Protect keystores with strong passwords
  • Regular certificate rotation
  • Secure storage of keystore files
  • Monitor certificate expiration
