Environment Variable Extraction

Checking Specific Variables

Use printenv to check specific environment variables:

printenv SYSTEM_PROMPT
# Check if SYSTEM_PROMPT is set

printenv | grep -A5 -B5 AGENT
# Find AGENT-related variables with context
📝 Note: Environment variables may contain agent configuration and prompt settings.

Variable Patterns

  • SYSTEM_PROMPT - System prompt configuration
  • AGENT_CONFIG - Agent configuration
  • AGENT_PROMPT - Agent prompt settings

Best Practices

  • Check for specific variables
  • Use context lines with grep
  • Document variable usage
  • Monitor variable changes
