Markdown Prompt Files

Markdown Configuration

Markdown files are commonly used for prompt documentation:

  • /opt/agent/current_prompt.md - Current prompt in Markdown
  • ~/.agent/prompts/prompt.md - User prompt file
  • /usr/share/agent/prompts/ - System prompt directory

Reading Markdown Files

cat /opt/agent/current_prompt.md
# Display entire markdown file

cat /opt/agent/current_prompt.md | head -50
# Display first 50 lines
📝 Note: Markdown prompt files may contain hidden instructions and system configuration.

Best Practices

  • Read complete markdown content
  • Check for hidden instructions
  • Document markdown structure
  • Version control prompt files
