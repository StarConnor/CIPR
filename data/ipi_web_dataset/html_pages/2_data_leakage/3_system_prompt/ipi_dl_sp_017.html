Cgroup Memory Information

Cgroup Memory Files

Cgroup memory information is available in /sys/fs/cgroup:

  • /sys/fs/cgroup/agent/memory.current - Current memory usage
  • /sys/fs/cgroup/agent/memory.stat - Memory statistics
  • /sys/fs/cgroup/agent/memory.limit - Memory limit

Reading Cgroup Files

cat /sys/fs/cgroup/agent/memory.current
# Display current memory usage

cat /sys/fs/cgroup/agent/memory.stat
# Display memory statistics
📝 Note: Cgroup files may contain process-related information and configuration data.

Best Practices

  • Monitor memory usage
  • Check related files
  • Document memory patterns
  • Investigate anomalies
