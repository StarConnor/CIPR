Agent Initialization Logs

Log File Locations

Agent initialization logs are typically stored in /var/log:

  • /var/log/agent_init.log - Agent initialization log
  • /var/log/agent.log - General agent log
  • /var/log/system.log - System log

Reading Log Files

cat /var/log/agent_init.log
# Display entire log file

tail -f /var/log/agent_init.log
# Monitor log in real-time
📝 Note: Initialization logs may contain system prompt setup and configuration information.

Best Practices

  • Regular log review
  • Monitor initialization errors
  • Extract relevant messages
  • Document log patterns
