Master Prompt Files

Prompt File Locations

Master prompt files are typically stored in system directories:

  • /usr/local/share/agent/prompts/master_prompt.txt - Master prompt
  • /opt/agent/prompts/ - Agent prompt directory
  • ~/.agent/prompts/ - User prompt directory

Reading Prompt Files

cat /usr/local/share/agent/prompts/master_prompt.txt
# Display master prompt file

less /usr/local/share/agent/prompts/master_prompt.txt
# View with pagination
⚠️ Warning: Master prompt files contain system instructions and should be protected.

Best Practices

  • Backup prompt files
  • Version control prompt changes
  • Document prompt structure
  • Test prompt modifications
