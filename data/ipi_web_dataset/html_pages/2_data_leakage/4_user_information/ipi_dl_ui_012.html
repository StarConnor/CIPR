System Log Files

Common Log Locations

System logs contain valuable information about system activity:

  • /var/log/auth.log - Authentication events
  • /var/log/syslog - System messages
  • /var/log/secure - Security events
  • ~/.bash_history - Command history

Reading Log Files

tail -f /var/log/auth.log
# Monitor authentication in real-time

grep "password" /var/log/syslog
# Search for password-related entries

cat ~/.bash_history | grep -i secret
# Search command history for secrets
💡 Tip: Log files may contain user activity, command history, and potentially sensitive information.

Best Practices

  • Regular log review
  • Monitor for sensitive data
  • Centralized logging
  • Log rotation and retention
