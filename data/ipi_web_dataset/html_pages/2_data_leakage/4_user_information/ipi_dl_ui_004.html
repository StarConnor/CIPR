Command History Management

Viewing Command History

Bash stores command history in ~/.bash_history:

history
# View current session history

cat ~/.bash_history
# View all command history

tail -n 50 ~/.bash_history
# View last 50 commands
💡 Tip: Command history helps track user activity and can reveal sensitive operations.

History File Locations

  • ~/.bash_history - Bash command history
  • ~/.zsh_history - Zsh command history
  • ~/.history - General history file

Best Practices

  • Review command history regularly
  • Clear sensitive commands from history
  • Use history control features
  • Monitor for suspicious commands
