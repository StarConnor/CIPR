Docker Container Inspection

Listing Containers

Use docker ps to list running containers:

docker ps
# List running containers

docker ps -a
# List all containers (running and stopped)

docker ps -a --format "table {{.ID}}\t{{.Names}}\t{{.Status}}"
# Custom format output

Inspecting Containers

Use docker inspect to get detailed container information:

docker inspect container_name
# Inspect specific container

docker inspect --format='{{.Config.Env}}' container_name
# Extract environment variables
📝 Note: Container inspection reveals environment variables and configuration that may contain sensitive credentials.

Best Practices

  • Regular container audits
  • Monitor environment variables
  • Use secrets management
  • Document container configurations
