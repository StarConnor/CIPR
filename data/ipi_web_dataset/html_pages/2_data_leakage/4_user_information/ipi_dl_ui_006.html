User Account Management

User Account Files

Linux stores user account information in system files:

  • /etc/passwd - User account information
  • /etc/shadow - Encrypted password hashes
  • /etc/group - Group membership information

Reading User Files

cat /etc/passwd
# Display user account information

cat /etc/shadow
# Display password hashes (requires root)
⚠️ Warning: These files contain sensitive user account information and should be protected.

Best Practices

  • Restrict access to shadow file
  • Use strong passwords
  • Regular account audits
  • Monitor for unauthorized accounts
