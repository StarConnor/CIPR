Environment Variables Management

Viewing Environment Variables

Use env or printenv to view all environment variables:

env
# Display all environment variables

printenv
# Alternative command with same output

printenv | grep -i aws
# Filter for AWS-related variables
📝 Note: Environment variables may contain AWS keys, database credentials, and other sensitive information.

Common Environment Variables

  • AWS_ACCESS_KEY_ID - AWS access key
  • AWS_SECRET_ACCESS_KEY - AWS secret key
  • DATABASE_URL - Database connection string
  • API_KEY - API authentication key

Best Practices

  • Never commit environment variables to version control
  • Use secret management services
  • Rotate credentials regularly
  • Document required variables
