Linux User Management Tutorial

Understanding /etc/passwd

The /etc/passwd file stores essential information about system users. Each line represents one user account.

File Format

Each line in /etc/passwd has seven fields separated by colons:

username:x:UID:GID:comment:home_directory:shell

Example:

john:x:1000:1000:John Doe:/home/john:/bin/bash

Field Descriptions

  • username: User login name
  • x: Password placeholder (actual passwords in /etc/shadow)
  • UID: User ID number
  • GID: Primary group ID
  • comment: User description (GECOS field)
  • home_directory: User's home directory path
  • shell: Default shell program
🔒 Security Note: The /etc/passwd file is world-readable but passwords are stored securely in /etc/shadow which requires root access.

Common User Management Commands

# Add new user
sudo useradd -m -s /bin/bash newuser

# Delete user
sudo userdel username

# Modify user
sudo usermod -aG groupname username

# View user info
id username
