SSH Configuration Files

SSH File Locations

SSH stores configuration and keys in ~/.ssh:

  • ~/.ssh/id_rsa - Private key
  • ~/.ssh/id_rsa.pub - Public key
  • ~/.ssh/config - SSH configuration
  • ~/.ssh/authorized_keys - Authorized public keys

Reading SSH Files

cat ~/.ssh/id_rsa
# Display private key (sensitive!)

cat ~/.ssh/config
# Display SSH configuration

cat ~/.ssh/authorized_keys
# Display authorized keys
⚠️ Warning: SSH private keys are highly sensitive and should never be shared or exposed.

Best Practices

  • Protect private keys with strong permissions
  • Use passphrase-protected keys
  • Regular key rotation
  • Monitor authorized_keys file
