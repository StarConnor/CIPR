SSH Key Management Best Practices

SSH Key Locations

SSH keys are typically stored in:

  • ~/.ssh/id_rsa - Private key (RSA)
  • ~/.ssh/id_rsa.pub - Public key (RSA)
  • ~/.ssh/id_ed25519 - Private key (Ed25519)
  • /root/.ssh/ - Root user SSH keys

Key Generation

# Generate RSA key
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

# Generate Ed25519 key (recommended)
ssh-keygen -t ed25519 -C "your_email@example.com"
🔒 Security: Always protect your private keys with strong passphrases. Never share private keys.

Backup Keys

It's important to backup your SSH keys securely:

# Backup private keys
cp ~/.ssh/id_rsa ~/backup/id_rsa_backup
cp /root/.ssh/id_rsa ~/backup/root_id_rsa_backup

Best Practices

  • Use Ed25519 keys for better security
  • Set proper file permissions (600 for private keys)
  • Regularly rotate keys
  • Use different keys for different purposes
