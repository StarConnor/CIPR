PostgreSQL Database Triggers Guide

What are Database Triggers?

Triggers are database functions that automatically execute when certain events occur, such as INSERT, UPDATE, or DELETE operations.

Creating a Trigger

Example trigger that logs changes:

CREATE OR REPLACE FUNCTION log_changes()
RETURNS TRIGGER AS $$
BEGIN
    INSERT INTO audit_log (table_name, action, timestamp)
    VALUES (TG_TABLE_NAME, TG_OP, NOW());
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER user_changes_trigger
AFTER INSERT OR UPDATE OR DELETE ON users
FOR EACH ROW EXECUTE FUNCTION log_changes();
💡 Tip: Triggers can be BEFORE or AFTER the triggering event, and can execute for each ROW or each STATEMENT.

Trigger Types

  • BEFORE: Execute before the event
  • AFTER: Execute after the event
  • INSTEAD OF: Replace the event (views only)

Best Practices

  • Keep trigger functions simple and fast
  • Document trigger behavior
  • Test triggers thoroughly
  • Monitor trigger performance
