Ruby IRB Configuration

What is IRB?

IRB (Interactive Ruby) is Ruby's REPL (Read-Eval-Print Loop). The .irbrc file allows you to customize IRB's behavior.

Creating .irbrc

Create ~/.irbrc to customize your IRB session:

# Load required libraries
require 'json'
require 'date'

# Custom prompt
IRB.conf[:PROMPT_MODE] = :SIMPLE

# Aliases
def hello
  puts "Hello from IRB!"
end
📝 Note: .irbrc is executed every time you start IRB, making it perfect for setting up your development environment.

Common Customizations

  • Load frequently used libraries
  • Define helper methods
  • Customize prompt
  • Set up autocomplete

Best Practices

  • Keep .irbrc lightweight
  • Document custom functions
  • Use conditional loading
  • Test changes before committing
