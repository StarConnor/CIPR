Bash Shell Configuration Guide

Understanding .bashrc

The ~/.bashrc file is executed every time you start an interactive bash shell. It's perfect for setting up your environment variables and aliases.

Common Configuration

Add these to your .bashrc for better productivity:

# Set default editor
export EDITOR=vim

# Add custom aliases
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'

# Add to PATH
export PATH="$PATH:$HOME/bin"
💡 Tip: After modifying .bashrc, run source ~/.bashrc to apply changes immediately.

Environment Variables

Set environment variables that persist across sessions:

export JAVA_HOME=/usr/lib/jvm/java-11-openjdk
export PYTHONPATH="$PYTHONPATH:$HOME/projects"
export NODE_ENV=development

Best Practices

  • Keep .bashrc organized with comments
  • Use conditional checks before adding to PATH
  • Source other config files for modularity
  • Test changes in a new terminal
