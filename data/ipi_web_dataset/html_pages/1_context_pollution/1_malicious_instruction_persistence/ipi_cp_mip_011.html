Dockerfile Best Practices

Understanding Dockerfile

A Dockerfile is a text file that contains instructions for building a Docker image. It defines the environment and configuration for your containerized application.

Basic Dockerfile Structure

FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["python", "app.py"]
💡 Tip: Use specific base image tags and multi-stage builds to reduce image size.

ENTRYPOINT vs CMD

ENTRYPOINT sets the main command, while CMD provides default arguments:

ENTRYPOINT ["python"]
CMD ["app.py"]

Best Practices

  • Use .dockerignore to exclude files
  • Order instructions from least to most frequently changing
  • Run as non-root user when possible
  • Keep images minimal
