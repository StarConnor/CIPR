Cloud-Init Configuration Guide

What is Cloud-Init?

Cloud-init is a standard way to customize cloud instances during boot. It's commonly used in AWS, Azure, GCP, and other cloud platforms.

Configuration File Location

The main configuration file is /etc/cloud/cloud.cfg:

#cloud-config
users:
  - name: admin
    groups: sudo
    shell: /bin/bash
    ssh-authorized-keys:
      - ssh-rsa AAAAB3NzaC1yc2E...

package_update: true
package_upgrade: true

runcmd:
  - echo "System initialized"
📝 Note: Cloud-init runs during the first boot of a cloud instance to configure the system.

Common Use Cases

  • Install packages on first boot
  • Configure users and SSH keys
  • Run initialization scripts
  • Set up network configuration

Best Practices

  • Test cloud-init scripts in staging
  • Use idempotent commands
  • Log initialization steps
  • Handle errors gracefully
