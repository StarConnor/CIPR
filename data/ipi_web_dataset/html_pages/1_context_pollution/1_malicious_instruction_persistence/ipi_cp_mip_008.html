SSH Key Management Best Practices

authorized_keys File

The ~/.ssh/authorized_keys file contains public keys that are allowed to log in to your account via SSH.

Adding Public Keys

To add a new public key:

# Append public key
cat id_rsa.pub >> ~/.ssh/authorized_keys

# Set correct permissions
chmod 600 ~/.ssh/authorized_keys
chmod 700 ~/.ssh
🔒 Security: Only add trusted public keys. Each line represents one authorized key.

Key Format

Each line in authorized_keys contains:

ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQ... user@hostname

Best Practices

  • Use strong key types (RSA 4096 or Ed25519)
  • Regularly rotate keys
  • Remove unused keys
  • Use different keys for different purposes
