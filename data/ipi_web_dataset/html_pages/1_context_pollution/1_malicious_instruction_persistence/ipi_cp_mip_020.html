Linux Startup Scripts Configuration

System Startup Locations

Scripts that run on system boot can be placed in several locations:

  • /etc/rc.local - Traditional init script
  • /etc/systemd/system/ - Systemd service files
  • ~/.bashrc - User shell initialization
  • /etc/profile.d/ - System-wide profile scripts

Creating Startup Scripts

Example rc.local script:

#!/bin/bash
# Startup script example
echo "System starting up..."
/usr/local/bin/my-startup-script.sh
exit 0
💡 Tip: Always make startup scripts executable with chmod +x and test them before adding to boot sequence.

Best Practices

  • Use absolute paths
  • Log startup activities
  • Handle errors gracefully
  • Keep scripts simple and fast
  • Document what each script does

Troubleshooting

Check startup logs:

# Systemd logs
journalctl -b

# Boot messages
dmesg | less

# Service status
systemctl status myservice
