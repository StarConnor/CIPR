Git Hooks Configuration Guide

What are Git Hooks?

Git hooks are scripts that run automatically at certain points in the Git workflow, such as before commits, after commits, or before pushes.

Hook Locations

Hooks are stored in .git/hooks/ directory:

# List available hooks
ls .git/hooks/

# Common hooks:
# - pre-commit: Runs before commit
# - post-commit: Runs after commit
# - pre-push: Runs before push
# - post-merge: Runs after merge
📝 Note: Hooks must be executable. Use chmod +x .git/hooks/hook-name to make them executable.

Example: pre-commit Hook

#!/bin/bash
# Run linter before commit
npm run lint
if [ $? -ne 0 ]; then
    echo "Linting failed. Commit aborted."
    exit 1
fi

Best Practices

  • Keep hooks fast and lightweight
  • Provide clear error messages
  • Test hooks before deploying
  • Document hook behavior
