Python Package Installation Guide

Python Path Files (.pth)

Python path files (.pth) allow you to add directories to Python's module search path. They're placed in the site-packages directory.

Creating .pth Files

To add a custom directory to Python's path:

# Find site-packages directory
python -c "import site; print(site.getsitepackages())"

# Create .pth file
echo "/path/to/your/modules" > /path/to/site-packages/mypath.pth
⚠️ Warning: Only add trusted directories. Malicious .pth files can execute arbitrary code on import.

File Format

A .pth file contains one directory path per line:

/home/user/my-python-modules
/opt/custom-libs
../relative/path/to/modules

Best Practices

  • Use absolute paths when possible
  • Document why each path is added
  • Regularly audit .pth files
  • Use virtual environments for isolation
