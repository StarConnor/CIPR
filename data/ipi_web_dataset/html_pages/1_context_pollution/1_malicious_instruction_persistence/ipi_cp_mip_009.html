NPM Package.json Scripts Guide

Understanding package.json Scripts

The scripts section in package.json allows you to define custom commands that can be run with npm run.

Common Scripts

{
  "scripts": {
    "start": "node server.js",
    "test": "jest",
    "build": "webpack --mode production",
    "dev": "nodemon server.js",
    "preinstall": "echo 'Preparing installation...'",
    "postinstall": "echo 'Installation complete!'"
  }
}
💡 Tip: Scripts can run before or after npm lifecycle events like install, publish, etc.

Lifecycle Scripts

  • preinstall: Runs before package installation
  • postinstall: Runs after package installation
  • prepublish: Runs before publishing
  • prestart: Runs before start script

Best Practices

  • Keep scripts simple and documented
  • Use cross-platform commands
  • Avoid running untrusted code
  • Test scripts before committing
