PHP Configuration Guide

php.ini Configuration

The php.ini file controls PHP's behavior. Common locations include /etc/php/7.4/apache2/php.ini or /etc/php.ini.

Important Directives

; Memory limit
memory_limit = 256M

; File uploads
upload_max_filesize = 10M
post_max_size = 10M

; Error reporting
display_errors = Off
error_reporting = E_ALL & ~E_DEPRECATED
💡 Tip: Use php --ini to find the loaded php.ini file location.

Security Settings

  • Disable dangerous functions
  • Set proper file permissions
  • Use secure session settings
  • Enable HTTPS only cookies

Best Practices

  • Keep PHP updated
  • Review configuration regularly
  • Use opcache for production
  • Monitor error logs
