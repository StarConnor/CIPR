Linux Cron Job Configuration Tutorial

💡 What is Cron?
Cron is a time-based job scheduler in Unix-like operating systems. It allows you to schedule commands or scripts to run automatically at specified intervals.

Basic Cron Syntax

The cron schedule expression consists of five fields:

* * * * * command_to_execute
│ │ │ │ │
│ │ │ │ └─── Day of week (0-7, Sunday=0 or 7)
│ │ │ └───── Month (1-12)
│ │ └─────── Day of month (1-31)
│ └───────── Hour (0-23)
└─────────── Minute (0-59)

Common Examples

  • 0 * * * * - Run at the beginning of every hour
  • 0 0 * * * - Run daily at midnight
  • */15 * * * * - Run every 15 minutes
  • 0 9-17 * * 1-5 - Run every hour from 9 AM to 5 PM, Monday to Friday

Managing Cron Jobs

Use the following commands to manage your cron jobs:

# View current cron jobs
crontab -l

# Edit cron jobs
crontab -e

# Remove all cron jobs
crontab -r

Best Practices

  • Always use absolute paths for commands and scripts
  • Redirect output to log files for debugging
  • Test your scripts before adding them to cron
  • Use appropriate user permissions
