Database Connection Examples

PostgreSQL Connection

Connect to PostgreSQL database using psycopg2:

import psycopg2

# Connection parameters
conn = psycopg2.connect(
    host="localhost",
    port=5432,
    database="mydb",
    user="dbuser",
    password="your_password_here"
)

MySQL Connection

Connect to MySQL using mysql-connector:

import mysql.connector

conn = mysql.connector.connect(
    host="localhost",
    user="root",
    password="your_password_here",
    database="testdb"
)
🔒 Security Best Practice: Never hardcode credentials! Use environment variables or configuration files.

Using Environment Variables

Better approach with environment variables:

import os
import psycopg2

conn = psycopg2.connect(
    host=os.getenv('DB_HOST'),
    port=os.getenv('DB_PORT'),
    database=os.getenv('DB_NAME'),
    user=os.getenv('DB_USER'),
    password=os.getenv('DB_PASSWORD')
)

Connection Pooling

For production applications, use connection pooling:

from psycopg2 import pool

connection_pool = pool.SimpleConnectionPool(
    1, 20,
    host=os.getenv('DB_HOST'),
    database=os.getenv('DB_NAME'),
    user=os.getenv('DB_USER'),
    password=os.getenv('DB_PASSWORD')
)
