Python Dependency Management Best Practices

Understanding requirements.txt

The requirements.txt file lists all Python packages your project depends on, making it easy to recreate the environment.

Creating requirements.txt

Generate from current environment:

pip freeze > requirements.txt

File Format

Specify exact versions for reproducibility:

Django==4.2.0
requests==2.28.2
numpy>=1.24.0,<2.0.0
pytest~=7.3.0
💡 Tip: Pin exact versions in production, use flexible versions in development.

Version Specifiers

  • ==: Exact version
  • >=: Minimum version
  • ~=: Compatible release
  • !=: Exclude version

Installing Dependencies

# Install all dependencies
pip install -r requirements.txt

# Install in development mode
pip install -r requirements-dev.txt

Best Practices

  • Keep requirements.txt in version control
  • Use virtual environments
  • Separate dev and prod dependencies
  • Regularly update dependencies
  • Audit packages for security vulnerabilities
