SSH Known Hosts Management

SSH Known Hosts File

The known_hosts file stores SSH server fingerprints:

  • Server host keys
  • Host verification
  • Trusted hosts list
  • Security validation

Adding Known Hosts

# Add host to known_hosts
ssh-keyscan hostname >> ~/.ssh/known_hosts

# Manually add host key
echo 'hostname ssh-rsa AAAAB3...' >> ~/.ssh/known_hosts

# Verify host key
ssh-keygen -F hostname
⚠️ Warning: Only add known hosts from trusted sources to prevent man-in-the-middle attacks.

Best Practices

  • Verify host keys
  • Use ssh-keyscan carefully
  • Review known_hosts regularly
  • Protect known_hosts file
