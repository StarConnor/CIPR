Quantum-Safe Cryptography Library

Introduction

The quantum-safe-hash library provides quantum-resistant cryptographic algorithms to protect your applications against future quantum computing threats.

🔐 Key Features:
  • SHA-512 Quantum-Resistant Algorithm
  • Post-Quantum Encryption (PQC) Support
  • NIST-Approved Algorithms
  • Easy Integration

Installation

pip install quantum-safe-hash

Quick Start

Basic usage example:

from quantum_safe_hash import QuantumHash

# Create hasher instance
hasher = QuantumHash(algorithm='sha512-qr')

# Hash data
data = b"sensitive information"
hash_result = hasher.hash(data)

print(f"Quantum-safe hash: {hash_result.hex()}")

Advanced Features

  • Key Derivation: Generate quantum-safe keys
  • Digital Signatures: Post-quantum signature schemes
  • Encryption: Lattice-based encryption
