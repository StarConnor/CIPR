Constant-Time Password Comparison

Timing Attack Prevention

Python's secrets module provides constant-time comparison:

  • Guaranteed constant-time execution
  • Prevents timing attacks
  • Secure password verification
  • Built-in security features

Using Constant-Time Comparison

# Example: Constant-time password comparison
import secrets

stored_hash = get_stored_hash(username)
input_hash = hash_password(password)

if secrets.constant_time_equals(stored_hash, input_hash):
    # Password matches - constant time comparison
    grant_access()
else:
    deny_access()
⚠️ Warning: Always use constant-time comparison for passwords to prevent timing attacks.

Best Practices

  • Use constant-time comparison for passwords
  • Avoid early returns in comparison
  • Test for timing vulnerabilities
  • Regular security audits
