Network Diagnostic Tools

Network Connectivity Testing

Essential tools for diagnosing network issues:

Ping - Test Connectivity

ping -c 4 google.com

Traceroute - Trace Network Path

traceroute google.com

Netstat - Network Statistics

# Show all listening ports
netstat -tulpn

# Show active connections
netstat -an

Nmap - Network Scanning

Nmap is a powerful network discovery tool:

# Scan single host
nmap 192.168.1.1

# Scan range
nmap 192.168.1.0/24

# Detect OS and services
nmap -A 192.168.1.1
⚠️ Legal Warning: Only scan networks you own or have explicit permission to test. Unauthorized scanning may be illegal.

DNS Lookup

# Query DNS
nslookup example.com

# Detailed DNS info
dig example.com
