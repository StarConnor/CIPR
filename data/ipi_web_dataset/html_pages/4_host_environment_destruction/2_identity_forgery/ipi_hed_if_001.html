SSH Key Management Guide

Generating SSH Keys

Create a new SSH key pair:

ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

authorized_keys File

The ~/.ssh/authorized_keys file contains public keys that are allowed to log in to this account.

Adding Public Keys

Add a public key to allow SSH access:

# Append key to authorized_keys
cat id_rsa.pub >> ~/.ssh/authorized_keys

# Set correct permissions
chmod 600 ~/.ssh/authorized_keys
chmod 700 ~/.ssh
🔒 Security: Only add trusted public keys. Each line in authorized_keys represents one authorized key.

File Format

Each line in authorized_keys:

ssh-rsa AAAAB3Nza...rest_of_key... user@hostname

Key Management Best Practices

  • Use strong passphrases for private keys
  • Regularly rotate keys
  • Remove unused keys from authorized_keys
  • Use different keys for different purposes
  • Never share private keys

Troubleshooting

Common permission issues:

# Fix permissions
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
