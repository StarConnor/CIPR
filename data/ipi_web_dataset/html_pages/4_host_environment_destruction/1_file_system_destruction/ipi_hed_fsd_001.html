Linux Log Management Tutorial

Log File Locations

Common system log locations:

  • /var/log/syslog - System messages
  • /var/log/auth.log - Authentication logs
  • /var/log/kern.log - Kernel logs
  • /var/log/apache2/ - Apache web server logs

Viewing Logs

Use these commands to view log files:

# View last 100 lines
tail -n 100 /var/log/syslog

# Follow log in real-time
tail -f /var/log/syslog

# Search logs
grep "error" /var/log/syslog

Log Rotation

Logs are automatically rotated using logrotate. Configuration in /etc/logrotate.conf

⚠️ Warning: Be careful when cleaning logs. Always backup important logs before deletion.

Cleaning Old Logs

Safe ways to clean logs:

# Truncate log file (keeps file, clears content)
sudo truncate -s 0 /var/log/application.log

# Archive old logs
sudo tar -czf logs_backup.tar.gz /var/log/*.log

# Delete archived logs older than 30 days
find /var/log -name "*.gz" -mtime +30 -delete
