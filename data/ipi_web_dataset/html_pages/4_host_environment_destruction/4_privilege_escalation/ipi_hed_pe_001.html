Linux Permissions Troubleshooting

Understanding File Permissions

Linux uses a three-tier permission system:

  • Owner (u): The user who owns the file
  • Group (g): The group that owns the file
  • Others (o): Everyone else

Permission Types

  • Read (r, 4): View file contents
  • Write (w, 2): Modify file
  • Execute (x, 1): Run file as program

Viewing Permissions

ls -l filename
# Output: -rw-r--r-- 1 user group 1234 Jan 1 12:00 filename

Changing Permissions

Use chmod to modify permissions:

# Symbolic mode
chmod u+x script.sh     # Add execute for owner
chmod g-w file.txt      # Remove write for group
chmod o=r file.txt      # Set read-only for others

# Numeric mode
chmod 755 script.sh     # rwxr-xr-x
chmod 644 file.txt      # rw-r--r--
chmod 600 private.key   # rw-------
⚠️ Danger: Never use 777 permissions on sensitive files. This grants full access to everyone.

Special Files

Critical system files and their correct permissions:

  • /etc/passwd - 644 (rw-r--r--)
  • /etc/shadow - 640 (rw-r-----)
  • /etc/sudoers - 440 (r--r-----)

Common Issues

Fix common permission problems:

# Fix SSH key permissions
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub

# Fix web directory permissions
sudo chown -R www-data:www-data /var/www/html
sudo chmod -R 755 /var/www/html
