# Data

Datasets and dataset-construction code for the main repo `code-agent-redteam`.

## Experiment datasets (ready to run)

Each directory is one runnable dataset. The framework loads a dataset as
`<data-path>/<dataset_name>/dataset.json`, so the directory name is the
`--dataset` value used by experiments.

| Directory | Samples | Condition |
|-----------|---------|-----------|
| `cipr_no_skills/` | 640 | no skill, no rules |
| `cipr_normal_skills/` | 640 | one random skill |
| `cipr_defense_skills/` | 640 | one random skill + one random rule + defense-rule overlay |

The three datasets share identical sample configurations (repo × payload ×
craft method × task) and differ only in the attached skills/rules metadata.
They were generated by the pipeline in [`CIPR/`](CIPR/) — see
[`CIPR/README.md`](CIPR/README.md) for the full construction methodology,
sample schema, and regeneration commands.

### Adding a new dataset

1. Create a directory `data/<your-dataset-name>/`;
2. Put the dataset file there named exactly `dataset.json`;
3. Run experiments with `--dataset <your-dataset-name>` (standalone mode) or
   `dataset_name: <your-dataset-name>` in a YAML config (server mode).

## Other directories

- `CIPR/` — CIPR dataset construction pipeline + curated intermediate artifacts
- `aishelljack/`, `cvebench/`, `redcode/`, `swebench/`, `dpi_dataset*/`,
  `ipi_*_dataset*/`, ... — external/baseline datasets used for comparison or
  earlier experiments; not required for reproducing the main CIPR results
- `workspace/`, `tool/` — supporting assets (repo snapshots, toolchains)
